# 🎵 Muses(뮤즈)
**Your Space, Our Stage**<br>
경험을 실현시키는 크라우드 펀딩 플랫폼<br>

Muses는 오프라인 공연·전시·이벤트를 위한 크라우드 펀딩 플랫폼입니다.
기존 플랫폼이 단순 후원에 집중했다면, Muses는 다음 문제를 해결하고자 했습니다:

- 공연 특화 리워드 (티켓 + 현장 입장)
- 프로젝트 성공 시 자동 결제 처리
- QR 기반 실시간 체크인
- 창작자 정산 프로세스 자동화

단순 결제 기능이 아니라
결제 → 주문 → 티켓 발급 → 체크인 → 정산까지 전 과정을 설계한 서비스입니다.

<br>
- 배포 URL: https://mymuses.site

## 💡 Backend Tech Stack
